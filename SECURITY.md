# Security Policy

## Supported versions

Only the **latest release** of each project receives security fixes.
Please update to the newest version before reporting a problem.

## Reporting a vulnerability

**Please do not report security vulnerabilities in public issues, discussions or pull requests.**

Instead, use GitHub's private reporting:

1. Open the **Security** tab of the affected repository.
2. Click **Report a vulnerability**.
3. Describe the problem, how to reproduce it and what impact you expect.

If the button is not available for a repository, open a regular issue **without any technical details** and ask for a private way to contact me.

## What to expect

- I will confirm receipt as soon as I can.
- I will keep you updated while I investigate and work on a fix.
- Once a fix is released, the vulnerability may be disclosed publicly, with credit to you if you want it.

This is a personal project maintained in my free time, so response times can vary.
