# Support

Need help? Here is where to go.

## Questions about using a project

1. Read the project's **README** and documentation first.
2. Search the existing **issues**, because your question may already be answered.
3. If you still need help, open a new issue with the **❓ Question** template. Include the version you use and what you already tried.

## Bugs

Use the **🐞 Bug** template and describe how to reproduce the problem.

## Ideas and feature requests

Use the **💡 Enhancement** template.

## Security problems

Please do not post them publicly. See the [security policy](SECURITY.md).

## Response times

This is a personal project maintained in my free time, so replies can take a while. Thanks for your patience!
